# Museamo 0.4.0

A private stream of thoughts for Android and Windows.

- Capture thoughts from the app or a resizable Android home-screen widget.
- Find saved thoughts with search, hashtags, Gems, and Checklist tags.
- Keep original photo and video attachments, formatting, and optional post locations.
- Link your Android and Windows libraries directly on the local network.
- Export portable ZIP backups, and restore deleted thoughts or earlier versions from Recovery.
- Paper-and-ink themes and the Museamo lantern branding.

This is an early release. See the repository's device checklist and verification records for remaining physical-device checks. Exports do not include unfinished drafts. Export a backup before updating.
